## GNC Software Exercise 1: C Basics

In this exercise, you'll be coding a basic c program to keep track of students.

To start, head down to setup instructions in order to download the neccessary software and clone this repository.

Then head to exercise details for more information regarding what you will have to do.

### Exercise Details
In this exercise, you will be implementing students.c using the prototypes defined in students.h.

You should not edit any file other than `students.c`.
You do not need to look at any file other than `students.h` and `students.c`.

Make a new github branch with the command `git checkout -b <INSERT-BRANCH-NAME-HERE>`.

To run the tests, run the command `make` in the command line or with WSL (if using windows).
Once all tests have passed, commit your changes by running `git add .` and `git commit -m "<INSERT COMMIT MESSAGE HERE>"`. Then push your changes to the remote repository by running `git push origin <INSERT-BRANCH-NAME-HERE>`.
